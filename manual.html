01Making your first pattern

  1. Capture or load a soundOpen sampling to record. In the full version, you can also use LOAD → Sounds to import an audio file.
  2. Edit the sampleOpen edit sample, choose the sound, set the selection, and preview your edits.
  3. Assign a padOpen assign, choose a pad, and select the sound with Sample Select....
  4. Set the patternChoose a pattern and BPM. Use edit seq to set its length and grid resolution.
  5. Record your performanceReturn with main. Press REC, wait for the four-beat count-in, and play the pads. Press play / stop to finish.
  6. Refine and mixEdit events in edit seq, add pad effects in effect, and balance levels in mix out.
  7. Save and exportUse SAVE → Project to keep your work, and export to render a pattern as WAV. These features require the full version.

02Top screen & performance

PATTERN / POSITION
Choose the current pattern in the LCD. POSITION shows the playback location as bar, beat, and sixteenth-note position.
BPM
Use − and + to set the tempo from 40 to 240 BPM. Long-press the BPM value for numeric entry.
BANK & pads
Each bank contains 16 pads. The full version provides banks A–D, for 64 pads. Tap a pad to play its assigned sample.
mute / solo
Enable the mode, then select pads to mute or solo. Muting silences the selected pads; soloing isolates selected pads.
Multi level / Multi Pitch
Enable a mode and choose the source pad. The grid then plays that sound at 16 velocity levels or pitch settings. Only one Multi mode can be active at a time. Turn the mode off to return to normal pad playing.
note rep
Enable Note Repeat, choose 1/4, 1/8, 1/16, or 1/32 in the REPEAT selector, and hold a pad to repeat its sound at the selected rate. Repeats can be captured during sequence recording.
play / stop
Starts or stops sequence playback.
REC
From stopped, starts recording after a four-beat count-in. During playback, enables recording immediately. Press REC again to leave recording while playback continues.
main / undo
main returns to the top screen. undo restores the most recent supported edit when available. Undo is not a substitute for saving a project.

03Sampling

Open sampling to capture external audio or resample the app’s output.

  1. Choose Audio Input for a microphone or audio interface, or App Audio for the app’s own sound.
  2. For external recording, select the available input device and allow microphone access when requested.
  3. Choose Stereo, Mono L, or Mono R under Recording Channel. Mono L/R captures the chosen channel as a mono sample.
  4. Watch the L/R meters and adjust REC GAIN (0–200%). Reduce gain if the signal overloads.
  5. Record using the method below, then press Stop. Find the recorded sound in Manage Sounds and assign it to a pad.
Threshold recording
For Audio Input, enable Threshold and set the trigger level from −60 to 0 dB. Press ARM; recording begins when the incoming level crosses the threshold. While waiting, press Cancel to disarm.
Manual recording
With Threshold off, press Start Recording. With Threshold on, use Record Manually, or Recording Now while armed, to start immediately.
App Audio
Start recording and play pads or a sequence to capture the app’s output as a new sample.

04Sample Edit

Open edit sample. Select a pad’s sound, or use the sample-name selector to choose a temporary sample.

  1. Use the waveform zoom controls to inspect the sound.
  2. Adjust Start and End to define the working selection. The range readout shows its length.
  3. Choose an operation from Edit and adjust its controls.
  4. Use Preview to audition the result.
  5. Use Apply to commit the edit, or Save as New Sample to create a separate temporary sample from the edited selection.

The waveform editor has its own Undo and Redo controls. To preserve an original sound, create a new sample before committing changes.

Temporary is not a saved projectSave as New Sample adds a sound to the temporary list. Use SAVE to store a project or save selected sounds as WAV files.

05Edit operations

OperationWhat it does
SliceDivides a sample into regions for separate pad playback.
ReverseReverses the selected audio.
NormalizeAdjusts the peak level to the target set by Gain Increase. Preview the result before applying.
SilenceSilences the range specified by its Start and End controls.
Fade In / Fade OutGradually raises or lowers the level over the specified fade interval.
Time StretchChanges duration while preserving pitch. Length ranges from 50% to 150% in 10% steps; 100% keeps the original duration.
TrimKeeps the selected range and removes audio outside it.

Selection matters: the edited result is built from the selected Start–End range. Check both boundaries before applying or saving a new sample.

Stereo Split (L/R)

For a stereo source, Stereo Split (L/R) creates two mono temporary samples from the edited selection. Their names end in _Left and _Right. Assign or save them separately as needed.

06Slice: manual, auto & zones

Choose Edit → Slice and then Manual or Auto.

Manual slicing

  1. Start playback with the leftmost pad (A1).
  2. Press other pads during playback to add markers at the current position.
  3. Drag markers left or right on the waveform to refine the boundaries. Use the marker list to inspect positions or remove a marker.
  4. Use Slice End to set the end of the sliced material.

Auto slicing

  1. Choose Auto and adjust Sensitivity. Higher sensitivity detects smaller changes and generally produces more candidates.
  2. Check the Candidates count, then press Auto Slice.
  3. Audition the regions and refine their marker positions.

Editing zones

In zone mode, press a zone pad to select a region. Check its start, end, and length. Use Add Marker to This Zone to divide it further, or Delete This Zone to remove the selected zone. Use Back to Selection to return to the selection view.

Assigning the slices

Choose Pad Assign, review the assignment summary, and select the starting bank. Slices are assigned in order across pads and continue into following available banks when needed. Check the available capacity and destination pads before assigning.

Add to temporary adds the slice regions to the temporary sound list for later use. Save as New Sample creates a new sound from the edited selection; it does not itself assign every slice to a pad.

07Assign & pad playback

Open assign, select the pad to edit, and choose its sound with Sample Select.... Selecting none removes the sound assignment.

Tune / Pitch
Changes playback pitch from −24 to +24 semitones. Use Reset tune to return to the original pitch. Use Time Stretch in Sample Edit when you want to change duration while preserving pitch.
Poly / Mono
Poly allows overlapping voices. Mono cuts the previous voice when the pad is triggered again.
Mute Group
Choose OFF or Group 1–8. Pads in the same group cut off one another, which is useful for open and closed hi-hats.
Pad Link
Select one or more other pads to play together with this pad. Clear All removes its links.
ADSR
Attack controls the rise in level (0–1.5 seconds); Decay controls the fall to Sustain (0–1.5 seconds); Sustain sets the held level; Release controls the tail (0–2.5 seconds).

08Sequence Edit & patterns

Open edit seq to edit the current pattern. Select a pad and tap a grid cell to inspect its events.

STEP / VELOCITY / TUNE / Target
STEP shows the event position. Adjust VELOCITY for its level and TUNE for its pitch. Long-press the velocity or tune value for numeric entry. Target identifies the selected pad and position.
Insert Event
Adds an event for the current pad at the cursor.
Delete Event
Deletes events within the selected grid cell. A coarse grid cell may contain more than one recorded event.
All Clear
Clears all events for the selected pad in the current pattern. It does not clear every pad or delete the sound.
Move & cursor arrows
Move the selected event by one grid interval, or move the cursor without moving an event.
Previous / Next Event
Jump to the previous or next event.

Grid & quantize

Choose 1/4, 1/8, 1/16, 1/32, 1/64, or none. Quantize controls recording alignment; none leaves recording unsnapped. To quantize an existing selection, select a cell and press the quantize Apply button. This button is unavailable during recording.

Pattern management

Use the pattern selector to switch patterns. The adjacent icons add, duplicate, merge, rename, or delete a pattern. At least one pattern must remain. Set the length with the 1–4 bar selector; the trial version allows one bar.

Pattern Merge creates a new pattern from two or more patterns in your chosen order. Add patterns to the merge list, reorder them, enter a name, and press Create.

Four-bar limitMerging keeps only the first four bars when the combined length exceeds four bars.

09Delete events from multiple pads

Long-press edit seq for about half a second to open Delete PAD Events. Opening this screen stops playback and recording.

  1. Check the pattern name at the top.
  2. Select the pads whose events you want to remove. Each pad shows its event count.
  3. Use Select All with Events to select all pads containing events, or Clear Selection to start over.
  4. Check the event and pad totals, then press Delete … Events · … Pads.

This removes the selected pads’ events only from the current pattern. Samples remain assigned. Use undo to restore the deleted events.

10Song Mode

Open song mode to arrange patterns into a track. This feature requires the full version.

  1. Tap a pattern in the left-hand list to append it to the song. Add the same pattern again to repeat it.
  2. Drag entries in the song arrangement to reorder them. Use an entry’s delete control to remove it.
  3. Press SongPlayback to play the arrangement. Enable Loop to repeat the song.
Delete All
Clears the song arrangement.
Convert
Creates a new pattern from the arrangement in song order.
Convert has a four-bar limitThe converted pattern contains only the first four bars of longer arrangements. Keep the Song Mode arrangement to play the complete track.

11Effects & Sound Type

Open effect, choose a pad, and open Effect Settings.

  1. Select an effect for EFFECT 1 and, optionally, EFFECT 2. Audio passes through slot 1, then slot 2.
  2. Select a slot to show its parameters and adjust them while auditioning the sound.
  3. Use each slot’s enable switch to compare processed and bypassed sound. NONE leaves a slot without an effect.

The full version includes TAPE ECHO, DELAY, REVERB, CHORUS, FLANGER, PHASER, TREMOLO/PAN, DISTORTION, OVERDRIVE, FUZZ, WAH, ISOLATOR, and 4 BAND EQ. The trial includes TAPE ECHO and 4 BAND EQ.

Applying settings to several pads

Use Group Select and select the target pads. Open the effect settings to edit the selection. The selection summary’s Apply copies the preview pad’s effect settings to the selected pads. Clear or Clear All in the selection area clears the selection.

Presets

Use the parameter preset controls to save a named setting and recall it later. Presets can also be deleted from the preset menu.

Sound Type

Open Sound Type Settings to adjust the pad’s lo-fi character, including sample-rate and bit-depth processing. The sound-character options include 26K12BIT and 40K12BIT. Use the Sound Type enable control to compare the processed sound with bypass.

12Mix Out

Open mix out and select a pad bank.

Volume
Set each pad from 0% to 150% using its fader or value-entry control.
Pan
Place the pad between left (−100), center (0), and right (+100).
Meters & audition
Watch the stereo level meters and use each pad’s play control to check its sound while adjusting the mix.
Reset
Restores the current bank’s volume and pan settings to their defaults.

Balance individual pads first, then adjust the main output level as needed.

Play

Creates a copy.

Removes all temporary sounds and clears the assignments of pads using them.

14Saving, loading & importing

Save a project

  1. Press SAVE in the LCD and choose Project.
  2. Enter a project name. For an existing saved project, choose Overwrite or New File.
  3. Enable Sample(WAV) also Save to save assigned sample audio with the project.
  4. Save and check the result message.

For a new file, turning the sample option off saves patterns and settings without sample audio. On overwrite, turning it off updates patterns and settings while retaining assigned sample files and removing unassigned sample files.

Keep the audio with your workEnable the sample option when saving a self-contained project. To retain additional sounds from the temporary list, save them using Samples Only.

Save sounds only

Choose SAVE → Samples Only, enter a folder name, select the sounds, and save. Selected sounds are stored as WAV files in the device’s Sound folder. Patterns and settings are not included.

Load a project

Choose LOAD → Project and select a saved project on this device. Save the current work first if you want to keep it. Swipe left on a project in the list to delete it.

Load or import a sound

Choose the destination pad before opening LOAD → Sounds. Select a saved sound or use the file picker to load WAV, MP3, AIFF, CAF, or M4A audio. The selected sound is loaded into the indicated current pad and added to the temporary list.

15Exporting audio

  1. Check the pattern, pad assignments, effects, and mix.
  2. Press export on the top screen.
  3. Choose the pattern to render as a WAV file.
  4. Use the destination or sharing controls presented by the app to save or share it.

The export selector exports a pattern. A Song Mode arrangement is not selected directly here. Converting a song before export is subject to the four-bar pattern limit.

To export individual sounds, use SAVE → Samples Only.

17Troubleshooting

A pad makes no sound
Check its sound assignment, mute/solo state, pad volume, and main output level. A pad set to none has no sample to play.
Recording does not start
Check microphone permission, input-device selection, and the input meters. If armed recording stays at Waiting..., lower the threshold or choose Recording Now.
Only one side records
Check Recording Channel. Mono L and Mono R intentionally capture only one input channel.
My sample is not in the saved project
Check whether Sample(WAV) also Save was enabled. Projects save assigned samples; save other temporary sounds separately with Samples Only.
A long song becomes shorter after Convert
Converted patterns are limited to four bars. Play the full arrangement from Song Mode.
I want to remove notes but keep the sound
Use Delete Event, All Clear, or the long-press edit seq deletion screen. Deleting a sound in Manage Sounds also clears pads using it.
