How to Use MS-12

MS-12 is a sampler and step/realtime sequencer for iPhone, played in landscape orientation.

Making a track follows this flow:

  1. Record sounds on the Sampling screen (microphone, or App Audio resampling).
  2. Edit them on the Edit Sample screen (trim, fade, slice, etc.).
  3. Assign the edited sounds to pads and set how they play (Assign).
  4. Record a sequence on the TOP screen with REC.
  5. Fine-tune the recorded notes on the Edit Seq screen.
  6. Optionally add effects to pads (Effect).
  7. Balance the levels in Mix and write the pattern out with Export.

Each function is explained on the following pages.

TOP Screen

  1. LCD — Shows the current PATTERN (tap to switch patterns), the playback POSITION (bar.beat.16th) and the BPM (− / + buttons, 40–240; long-press the number to type a value). SAVE / LOAD save and recall projects.
  2. Function buttons — Open Sampling, Assign, Song, Mix, Edit Sample, Edit Seq, Effect and Export. The selected function is shown in the left area (or full screen for Mix, Edit Sample and Edit Seq; Assign keeps the pads on the left and shows the settings on the right). While resampling, Sampling blinks red and the other function buttons are disabled.
  3. BANK / mute / solo — Switch the pad bank (A–D), and mute or solo individual pads.
  4. Multi level / Multi Pitch — Spread one pad across all 16 pads at 16 velocity levels or 16 pitches.
  5. Transport — main returns to this TOP screen, undo reverts the last action, note rep turns note repeat on, play / stop starts and stops playback (it also works on the Edit Sample and Edit Seq screens), and the red button is REC (realtime recording).
  6. Pads — Tap a pad to play the sound assigned to it. The tapped pad also becomes the “current pad” used by other screens. Long-press a pad to quickly assign a sound from the temporary list.

MS-12 Quick Manual — 2

Pad Controls & Performance

BANK, mute and solo

BANK switches the 16 visible pads between banks A–D (64 pads in total, A1–D16). Press mute (red frame) and then tap pads to mute or unmute them; press solo (yellow frame) and tap a pad to hear only that pad. While pads are muted or soloed, pressing the button again clears all mutes / solos. Muted pads are silent everywhere, including during sequence playback.

Multi level / Multi Pitch

  1. Source pad / Change Pad — Shows the pad currently spread across the grid. Change Pad lets you pick another source pad.
  2. Level pads (L1–L16) — Each pad plays the source sound at a different velocity, from 6% (L1) to 100% (L16). In Multi Pitch mode the pads become P1–P16, from −7 to +8 semitones (P8 = original pitch).
  3. Multi level / Multi Pitch — Turn the mode on, then tap the source pad. The two modes cannot be on at the same time; they are available on the TOP screen only.

Recording a sequence (REC) and note repeat

When stopped, REC plays a 4-beat count-in (the count is shown on the button) and then starts playback and recording. During playback, REC punches in immediately; pressing it again stops recording while playback continues. A metronome clicks while recording. Hits are snapped to the grid set in Edit Seq (default 1/16; none = no quantize). With Multi level / Multi Pitch on, the velocity / pitch you play is recorded too.

note rep: while on, holding a pad retriggers it in time with the BPM. The rate is chosen with the REPEAT menu that appears (1/4, 1/8, 1/16, 1/32; default 1/16).

undo reverts the most recent sequence or pad change (sample assignment, slice-to-pad, Edit Sample “Apply”, Effect settings).

MS-12 Quick Manual — 3

Sampling Screen

Records an external input or the app’s own output and adds it to the temporary sound list. Open it with the Sampling button on the TOP screen.

  1. Audio Input / App Audio — Choose whether to record an input such as the microphone, or the sound the app itself is playing (resampling). Choosing App Audio starts resampling immediately and returns to the TOP screen (see the next page). The folder icon loads an audio file from the Files app into the temporary list.
  2. Input Device — Select the microphone or external audio interface to use. Rescan re-detects newly connected devices.
  3. Recording Channel — Record in Stereo, or only the left (Mono L) or right (Mono R) channel.
  4. Threshold — When on, recording starts automatically once the input exceeds the threshold level (−60 to 0 dB, default about −20 dB).
  5. Level meter (L / R) — Shows the input level in real time; the white line marks the threshold.
  6. ARM / Record Manually — ARM puts the recorder on standby (“Waiting…”) until the threshold is crossed; press again to stop. Record Manually starts recording immediately. With Threshold off the button reads Start Recording.
  7. REC GAIN — Adjusts the input level from 0% to 200% (shown in dB). 0dB resets it.
  8. Manage Sounds — Opens the list of recorded and imported sounds (next page).
MS-12 Quick Manual — 4

Resampling (App Audio)

Records the sound the app itself plays — pads, patterns and effects — as a new sample, so you can play and record at the same time.

  • Choose App AudioOn the Sampling screen, tap “App Audio”. Recording starts immediately and the app moves to the TOP screen.
  • PlayTap the pads and press play / stop as usual. Everything you hear is recorded.
  • FinishPress the blinking Sampling button once more. Recording stops and the result is saved to the temporary list (Sound 1, Sound 2…).
  1. Sampling (blinking red) — Shows that resampling is in progress. Press it again to finish and save.
  2. Other function buttons — Dimmed and disabled until resampling is finished.
  3. Pads / transport — Still available during recording: play pads, run the pattern with play / stop, use note rep and REC.
In the trial version, resampling stops by itself when the recording limit (10 seconds) is reached, and the recorded part is saved. The full version has no limit.
MS-12 Quick Manual — 5

Manage Sounds Screen

Manages all recorded, imported and sliced sounds in the temporary list. Open it with Manage Sounds on the Sampling screen.

  1. Temporary List — All sounds made so far; the number of items is shown on the right.
  2. Play — Hold to audition the sound. The name and length are shown next to it.
  3. Rename (pencil) — Changes the sound’s name (you can also double-tap the name).
  4. Duplicate — Makes a copy of the sound.
  5. Delete (trash) — Removes the sound from the list. Pads that use it are set to NONE.
  6. Delete Unassigned Sounds — Deletes every sound that is not assigned to any pad.
  7. Delete All Sounds — Deletes all sounds in the list.
New recordings are named Sound 1, Sound 2… Duplicate names automatically get _2, _3… added.
MS-12 Quick Manual — 6

Edit Sample Screen

Edits a sampled sound on its waveform. Open it with the Edit Sample button on the TOP screen; it opens full screen.

  1. Waveform — The waveform of the sample being edited (stereo samples show L and R).
  2. Zoom — Zoom in and out (100–800%). You can also pinch, and scroll with two fingers.
  3. Start / SelectRange / End — Start point, length and end point of the selected range.
  4. Sample selector — The sample being edited. Tap to switch to another sound from the temporary list.
  5. Edit — Opens the edit menu (Slice, Reverse, etc.). See the next page.
  6. Save as New Sample — Saves the edited range as a new sample in the temporary list. For stereo samples, Stereo Split (L/R) also appears (it saves the left and right channels as two separate mono samples).
  7. Undo / Redo — Steps back and forward through edits on this screen.
  8. Preview — Hold to hear the edited result.
  9. Apply — Commits the edit. Every pad that uses this sample is updated.
  10. Padcontrol panel Show / Hide — Shows or hides the pad panel below. It folds away automatically while most edit panels are open, but stays open while the Slice panel is open.
  11. Pad panel — Select the bank and the pad whose sample you want to edit.
Edit while the pattern plays. play / stop in the transport section works on this screen, so you can start the pattern and keep editing. Press Apply to hear the edited sample in the pattern.
MS-12 Quick Manual — 7

Edit Sample Menu

The menu opened with the Edit button on the Edit Sample screen. Each function opens a parameter panel below the waveform.

  1. Slice — Splits the waveform across several pads (see the following pages). Mono samples only.
  2. To Mono — New. Converts a stereo sample to mono, keeping only the left or right channel (next page). Greyed out for samples that are already mono, as shown.
  3. Reverse — Plays the waveform backwards.
  4. Normalize — Raises the level automatically so the peak reaches the target (Gain Increase 0–100%).
  5. Silence — Makes the selected range silent.
  6. Fadeout — Gradually lowers the level towards the end of the range.
  7. Fadeinterface — Fade in: gradually raises the level from the start of the range.
  8. Time Stretch — Changes the length (50–150%) while keeping the pitch.
  9. Trim — Keeps only the selected range and removes the rest (drag the handles or enter Start / End). Scroll the menu to show it.
Edits are processed in the order To Mono → Trim → Time Stretch → Fade In → Fade Out → Silence → Normalize → Reverse. Trim is applied only while the Trim panel is open when you press Preview or Apply.
MS-12 Quick Manual — 8

To Mono — Stereo to Mono

Converts a stereo sample into a mono sample by keeping one channel. Open it with Edit → To Mono on a stereo sample.

  1. To Mono — The edit menu (now showing To Mono). The panel opens with L (Left) selected.
  2. Off / L (Left) / R (Right) — Choose which channel to keep. Off leaves the sample stereo.
  3. Preview / Apply — Hold Preview to listen. Apply replaces the sample with the mono version.
After applying, the waveform changes from two rows (L / R) to one, and Slice, which needs a mono sample, becomes available. It can be combined with Trim, Fade, Normalize and the other edits. To keep both channels as separate samples instead, use Stereo Split (L/R).
MS-12 Quick Manual — 9

Slice Function ① — Basics

Splits one sample into several sounds and assigns them to separate pads. Open it with Edit → Slice.

  1. Sample — The source sample to slice.
  2. Slice — The edit menu (now showing Slice).
  3. Save as New Sample — Saves the unsliced sample as a new sample.
  4. Manual — Add slice markers by hand while listening (next page).
  5. Auto — Analyzes the waveform and places slice points automatically (next page).
  6. Preview — Hold to listen.
  7. Apply — Commits the edit.

Manual slicing

Choose Manual. The pad panel stays open while the Slice panel is shown (see the next page). Tap the leftmost pad to play the sample once; while it plays, tap the other pads to drop markers (M1, M2…) at the playback position. The marker list shows each position (m:ss.sss); ⊗ deletes a marker and the trash button clears them all. Back to Selection returns to the Manual / Auto choice.

MS-12 Quick Manual — 10

Slice Function — Pad Panel

The pad panel is always shown while the Slice panel is open, so you can place markers with the pads right away.

  1. Pad panel — Stays visible during slicing. Tap the leftmost pad (A1) to start playback, then tap the other pads to add markers.
  2. Pad Slice — The instruction for the Manual mode. Back to Selection returns to the Manual / Auto choice.
  3. Padcontrol panel Show / Hide — For other edit panels (Trim, Fade, To Mono, etc.) the pad panel folds away while the panel is open; Slice keeps it open.
Because play / stop also works on this screen, you can run the pattern while you slice a sample.
MS-12 Quick Manual — 11

Slice Function ② — Auto Slice

Choose Auto to analyze changes in level and detect slice points automatically.

  1. Sensitivity — Detection sensitivity (0–1). Moving it right detects smaller changes and produces more slices.
  2. Candidates — The number of slice candidates found at the current sensitivity.
  3. Auto Slice — Runs the analysis and places the slice markers on the waveform.
  4. Candidate lines — Orange lines preview where slices will be placed.
If no slice can be detected, raise the sensitivity and try again. Detected points are at least 60 ms apart.
MS-12 Quick Manual — 12

Slice Function ③ — Editing Zones

Once markers exist, the sample is divided into colour-coded zones and the pads become zone pads (Z1, Z2…).

  1. Markers (M1, M2…) — Slice boundaries. Drag a marker left or right to adjust it.
  2. Selected zone — The zone chosen with a zone pad is highlighted.
  3. Add Marker to This Zone — Splits the selected zone in the middle.
  4. Delete This Zone — Merges the selected zone with its neighbour.
  5. Pad Assign — Assigns all slices to pads in one go (next page).
  6. Add to temporary (n) — Adds all slices to the temporary list (the count is shown).
  7. Undo / Redo — Reverts marker edits.
  8. Preview — Hold to listen.
  9. Save Zone as New Sample — Saves only the selected zone as a new sample (<name>_ZoneN).
  10. Zone pads (Z1…) — Tap to hear a zone and select it for editing.
MS-12 Quick Manual — 13

Slice Function ④ — Assigning to Pads

Use Pad Assign to place all slices onto pads at once.

  1. Assign destination – Bank Select — Shows how many slices will be assigned. Slices beyond the 16 pads of one bank continue automatically into the next bank.
  2. Assign to Bank A / B / C / D — Choose the first bank. The slices are placed in order on its pads (A1, A2…), named slice1, slice2… and added to the temporary list.
MS-12 Quick Manual — 14

Assign Screen

Assigns a sound to each pad and sets how it plays. Press the Assign button on the TOP screen: the pads stay on the left and the settings of the selected pad appear on the right. Tap another pad to switch to it.

  1. Pads — Tap a pad to select it (red frame) and hear it. The settings on the right always belong to the selected pad.
  2. Pad Settings — The selected pad and its sample name. ▶ previews the pad.
  3. Sound — Choose the sample for this pad from Sample Select… (temporary list), or none. Reset to Default clears it.
  4. Tune (Pitch) — Raises or lowers the playback pitch in semitones (−24 to +24). Drag the slider or type a value in the large number box. The length changes with the pitch.
  5. Select pads… — Applies the tune to several pads at once (next page).

Scroll the settings to reach the rest of the items (next page). The transport buttons (main, undo, note rep, play / stop, REC) stay at the bottom right.

MS-12 Quick Manual — 15

Assign Screen — More Settings

  1. Poly / Mono — Poly lets notes overlap; Mono always plays only one note (a new hit cuts the previous one).
  2. Mute Group — Pads in the same group (1–8) stop each other when played — for example open/closed hi-hats.
  3. Pad Link — Choose other pads that play at the same time whenever this pad plays.
  4. ADSR (Attack / Decay / Sustain / Release) — Sets the volume envelope from the start of the sound until it fades. Attack is how fast it rises (0–1.5 s), Decay the initial drop (0–1.5 s), Sustain the held level (0–1), and Release the tail after the sound stops (0–2.5 s).

Tuning Several Pads at Once

  1. Select pads… / Done — Press Select pads… to enter selection mode (the button turns red and reads Done). Press Done to leave it.
  2. Target pads — In selection mode, tap pads on the left to add or remove them (red frames). Tapping does not play the pad. The chosen pads are listed next to the button (“Also: A3, A6”).

While pads are selected, the slider, the number box and Reset tune change the tune of the selected pad and all chosen pads together. A pad takes on the current tune value when it is added. The selection is cleared when you switch to another pad.

MS-12 Quick Manual — 16

Edit Seq Screen

Edits a recorded pattern step by step. Open it with the Edit Seq button on the TOP screen; it opens full screen. The grid shows the lane of the pad selected in the pad panel.

  1. Pad trigger — Tap to write a note at the cursor (when stopped) or at the playback position (when playing).
  2. Timeline — Notes (events) for the selected pad. Brightness shows velocity; tap to select a note or move the cursor.
  3. STEP / VELOCITY / TUNE / Target — Position (bar.beat.tick), velocity (0–100%) and pitch (±24 st) of the selected note, adjustable on the spot. Reset restores 100% / ±0.
  4. Pattern — Choose the pattern to edit; + adds, then duplicate, rename and delete.
  5. Bars — Pattern length, 1–4 bars (default 2).
  6. Grid — Grid resolution: 1/4, 1/8, 1/16, 1/32, 1/64 or none. Also used to quantize realtime recording.
  7. Apply — Quantizes the selected note to the grid.
  8. Insert Event / Delete Event / All Clear — Add a note at the cursor, delete the selected note, or clear every note of this pad in the pattern.
  9. ◀ Move / Move ▶ / Previous Event / Next Event — Move the selected note one grid step, or jump to the previous / next note.
  10. « / » — Move the cursor one grid step.
  11. Now — Current playback position and progress.
  12. Pad panel — Switch the pad (track) you are editing.
  13. Transport — undo, main, note rep, play / stop and REC work here as on the TOP screen.
Long-press the Edit Seq button to open Delete PAD Events, which clears all notes of the selected pads in the current pattern (samples stay assigned; undo restores them).
MS-12 Quick Manual — 17

Song Mode Screen

Chains several patterns to set the playback order of a whole song. Open it with the Song button on the TOP screen.

  1. Playback — Play and stop the song with play / stop on the TOP screen. During playback, “Playback: n / N” shows the current position.
  2. Patterns — The list of patterns. Tap ⊕ to append a pattern to the song.
  3. Song arrangement — The playback order. Drag items to reorder them; the playing item turns green.
  4. Remove (⊖) — Removes an item from the song (you can also swipe).
  5. Delete All — Removes every item from the song.
Each item plays once, then the next one; playback stops after the last item. While Song is selected, play on the TOP screen plays the song. Opening Edit Seq or choosing a pattern on the LCD returns to pattern playback.
MS-12 Quick Manual — 18

Effect Screen

Applies effects to the sound of each pad. Open it with the Effect button on the TOP screen.

  1. Select Pads — Tap a pad to choose (and hear) the pad to process.
  2. Group Select — Select several pads at once. Select All / Clear help with selection, and Apply copies the current pad’s effect settings to all selected pads.
  3. Effect settings for … — Sets the effect types and parameters for the selected pad(s) (next page).
  4. Sound Type Settings — Sets the lo-fi character of the pads (Aliasing, Ring Mod, Compressor, Saturation, Punch).
Signal chain per pad: Sound Type (Aliasing → Saturation → Punch → Ring Mod → Compressor) → EFFECT 1 → EFFECT 2 → ADSR → velocity / pitch → volume / pan.

Mix Screen (Mixer)

Adjusts the volume balance of the pads. Open it with the Mix button on the TOP screen; it opens full screen.

  1. PAD BANK — Switch the bank (A–D) to adjust.
  2. Reset — Returns the faders and pans of the current bank to 100% / centre.
  3. PAN — Sets the left / right position (L100 – C – R100). Long-press to type a value.
  4. Volume fader — Sets each pad’s volume from 0% to 150% (the value turns orange above 100%). Long-press to type a value.
  5. Level meter — Shows the output level of the pad (−60 to 0 dBFS, with peak hold).
  6. Play — Hold to audition the pad.
  7. ‹ / › — Show the previous / next 4 channels (you can also swipe).
  8. main — Return to the TOP screen.
MS-12 Quick Manual — 22

Saving & Loading

SAVE (Project Save)

  1. Save — Saves with the current settings (Cancel closes the sheet).
  2. SaveMode — Project saves the whole project; Samples Only saves selected sounds as WAV files into a folder in Sound.
  3. Save destination — Project name (default Project_yyyyMMdd_HHmmss). When a project is open you can choose Overwrite or New File.
  4. Sample(WAV) also Save — Also saves the assigned samples as WAV. Turn off to save only patterns and settings.

LOAD (Project / Sound Load)

  1. Load Item — Project lists saved projects (newest first; swipe left to delete). Sounds loads single sounds.
  2. Choose a sound file on this iPhone — Loads a WAV / MP3 / AIFF / CAF / M4A file from the Files app into the current pad.
  3. Sound list — Audio files in the app’s Sound folder; tap one to load it into the current pad and the temporary list.
  4. Preview — Plays the file.
MS-12 Quick Manual — 23

Export

Writes a pattern to a WAV file. Press the Export button on the TOP screen.

  1. Export — Opens “Select a sequence to export”.
  2. Pattern buttons — Choose the pattern to write out. The result (file path and length) is shown when finished.

Exports are 44.1 kHz / 16-bit mono WAV files and include all pad effects, mute groups, Mono cuts and pad links. Mute / solo states are not applied. The file length runs to the end of the last sound.

Where Files Are Saved

All data is stored in the app’s folder, visible in the Files app under On My iPhone › MS-12.

FolderContents
Project/<name>/Projects: project.json and a Samples folder with the WAV files
Sound/Imported sounds and “Samples Only” saves (sub-folders allowed)
Export/Exported patterns (<PatternName>.wav; _1, _2 are added if the name exists)

A project stores the BPM, patterns, song order, pad assignments and every pad setting (volume, pan, tune, ADSR, voice mode, mute group, links and effects). Mute / solo states and unassigned temporary sounds are not saved.
